### 7. Failure handling

- Backend HTTP client `exec_request()` sends once and treats any non-2xx status as an error string containing method, URL, status, content-type, and body. It does not implement status-specific retry in this client method. Source: `codex-rs/backend-client/src/client.rs:234-253` @ `98d28aab54ed86714901b6619400598598876dd0`.
- The app-server consume processor wraps backend consume in a 10-second timeout. Timeout maps to internal error `rate limit reset consume timed out`; backend/network/decode errors map to internal error `failed to consume rate limit reset: {err}`. Source: `codex-rs/app-server/src/request_processors/account_processor/rate_limit_resets.rs:1-31`, `codex-rs/app-server/tests/suite/v2/rate_limit_reset_credits.rs:142-163`, `codex-rs/app-server/tests/suite/v2/rate_limit_reset_credits.rs:167-205` @ `98d28aab54ed86714901b6619400598598876dd0`.
- The TUI wraps reset-credit read and consume JSON-RPC calls in `RATE_LIMIT_RESET_REQUEST_TIMEOUT`; timeout strings are `account/rateLimits/read timed out in TUI` and `account/rateLimitResetCredit/consume timed out in TUI`. Source: `codex-rs/tui/src/app/background_requests.rs:121-161` @ `98d28aab54ed86714901b6619400598598876dd0`.
- For reset-credit read failure while opening option 2, TUI displays `Couldn't load usage limit resets. Please try again.` Source: `codex-rs/tui/src/chatwidget/usage.rs:132-145` @ `98d28aab54ed86714901b6619400598598876dd0`.
- For consume failure, TUI displays `Couldn't reset usage. Please try again.` and offers `Try again`/`Close`; `Try again` reuses the same idempotency key. Source: `codex-rs/tui/src/chatwidget/usage.rs:282-306`, `codex-rs/tui/src/chatwidget/tests/usage.rs:369-386` @ `98d28aab54ed86714901b6619400598598876dd0`.
- 401/403/429/5xx are not given distinct reset-specific UI handling in this path. They are non-2xx statuses from `exec_request()` and flow into the same app-server/TUI error handling as other backend failures. Source: `codex-rs/backend-client/src/client.rs:248-251`, `codex-rs/app-server/src/request_processors/account_processor/rate_limit_resets.rs:25-31`, `codex-rs/tui/src/chatwidget/usage.rs:282-306` @ `98d28aab54ed86714901b6619400598598876dd0`.
